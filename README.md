# Marketing Campaign Conversion Analysis

## Project Overview
This project analyses bank marketing campaign data to understand customer responses and conversion patterns across different campaign characteristics.

## Objectives
- Measure overall campaign conversion rate.
- Compare conversion rates by contact channel.
- Analyse conversion patterns across age groups.
- Examine previous campaign outcomes.
- Study the relationship between campaign contact frequency and conversion.

## Dataset
The project uses the UCI Bank Marketing dataset, specifically `bank-additional-full.csv`.

The cleaned dataset contains **41,176 records** after duplicate removal.

## Tools Used
- Python
- Pandas
- Google Colab
- Power BI

## Data Cleaning
- Checked for missing values.
- Identified and removed duplicate records.
- Created age groups for comparative analysis.

## Key Findings
- Total contacts analysed: 41,176
- Successful conversions: 4,639
- Unsuccessful responses: 36,537
- Overall conversion rate: 11.27%
- Non-conversion rate: 88.73%
- Cellular contacts had a higher conversion rate than telephone contacts in this dataset.
- Customers with a successful previous campaign outcome had a higher conversion rate than the other previous-outcome groups.

These findings describe associations in the dataset and do not establish causation.
